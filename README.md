
# Network_game
A basic game to test Godot Networking. 

The game contains a Lobby that allows the player to set a name for the room, host a game, or join into a created game.

The lobby game was made primarily following the Client-Server Photon Godot Fusion documentation.

I have opted to design a simple 2D game, with an arena and one character for reach player. The characters can shoot, and die in one shot, then revive. The player with most kills at the end of the game wins.
